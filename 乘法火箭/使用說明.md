# 乘法火箭 使用說明

2～10 的乘法輸入題遊戲，只有 `index.html` 一個檔案，不需要網路。

## 放到手機／平板
- **Android**：把 `index.html` 複製到手機，用 Chrome 開啟（例如網址列輸入 `file:///sdcard/Download/index.html`）。
- **iPhone／iPad**：「檔案」App 預覽時遊戲不會動。可以用 Documents by Readdle 這類有內建瀏覽器的 App 開啟，或放到 GitHub Pages、區網伺服器用 Safari 開，再「加入主畫面」。
- 成績存在該瀏覽器裡；換瀏覽器、換裝置或清除網站資料，紀錄會歸零。

## 玩法
| 模式 | 說明 |
|---|---|
| 🚀 60 秒火箭挑戰 | 每題 10 分；連對 5 題起 ×2、10 題起 ×3；2 秒內答對 +5；答錯扣 2 秒。成績進前 5 名排行榜 |
| 👻 影子對手 | 挑戰時顯示第 1 名紀錄同一秒的分數，即時看到「領先／落後」幾分 |
| 🎯 乘法表練習 | 選 2～10 其中一個乘法表練 2 輪，答錯的會再出一次，完成得徽章 |
| 🔥 弱點特訓 | 自動挑 15 題最常錯、最慢的題目 |
| 🗺️ 精熟地圖 | 81 格熟練度（✔ 熟練、… 偏慢、✖ 常錯），全綠成為乘法大師 |
| 🌍 火箭等級 | 累積答對 50／150／300／500／800 題，依序飛到月球、火星、木星、土星、銀河 |

- 輸入到正確答案會自動判定，不必按 ✔；位數打滿但不對就算錯。
- 電腦也可以用鍵盤數字鍵、Backspace、Enter 操作。
- 清除紀錄：精熟地圖頁最下方「家長設定」。
